Context Memory API for AI Applications

Store and retrieve context for any AI application.

One API to store memories, documents, knowledge graphs, and events. Multi-signal retrieval with Reciprocal Rank Fusion returns token-budgeted context bundles ready for Claude, GPT, Gemini, or local models.

store_memory.py 
import requests

response = requests.post(
    "https://your-instance/api/v1/store",
    headers={"Authorization": "Bearer cqx_..."},
    json={
        "type": "memory",
        "memoryType": "FACT",
        "content": "User prefers dark mode",
        "importance": 0.9
    }
)

# Retrieve context for an LLM call
bundle = requests.post(
    "https://your-instance/api/v1/context/build",
    headers={"Authorization": "Bearer cqx_..."},
    json={
        "query": "What are the user's preferences?",
        "tokenBudget": 4000
    }
).json()

Built for Developers

Store Any Context

One endpoint handles memories, documents, knowledge graph entities, relationships, and timeline events. Automatic chunking, embedding, and indexing.

Multi-Signal Retrieval

Five retrieval signals — vector similarity, BM25 full-text, knowledge graph traversal, scored memory, and behavioral events — merged through Reciprocal Rank Fusion.

Token-Budgeted Bundles

Context bundles fit your model's token window. The optimizer ranks, compresses, and formats retrieved items. No more truncation or wasted context.

Knowledge Graph

Store entities and relationships with automatic traversal. Graph context feeds into retrieval — related entities boost recall without explicit joins.

Webhooks & Events

Track user behavior and system events. Get notified when context changes. Build reactive pipelines around your AI application's memory.

One API Key

Generate a scoped API key. Authenticate with a Bearer token. All endpoints — store, recall, retrieve, build — are available immediately. No setup complexity.
